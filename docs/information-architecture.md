# Where content lives (2026-11-17)

The WordPress site grew page by page; several pages held one or two sentences, and the same text sat in
several places. Every URL stays; what changes is which page carries what, and the menu.

| Publications | Overview `/publications/` | Links to the paper archive, conference posters and recorded talks |
