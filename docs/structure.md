## WordPress numeric URLs

Apache sends the p and page_id query parameters on / and /index.php to their trailing-slash paths for the 69 known IDs in tests/migration.json. The search query s opens client-side search on the requested page.

## Media and legacy hosts

Inline media use Hugo Pipes. Linked downloads retain upload paths. Files under /published_manuscripts/ and the separately hosted Horn CV stay absolute. Netstim Berlin aliases of mirrored pages are rebased to their local routes. External links retain their targets.

## Production and preview routing

Production uses https://www.netstim.org/. Pages builds from the project URL with the preview parameter enabled. Local links use the base path and canonicals use the production address. Git history supplies the fallback last-modified dates.
